- SHA-256: `d3124ab24a6f2201a03673cde5a416d04c78dd44985a3c7d590c48efc7e89d3c` (asserted by `src/evaluate_final.py` before any evaluation)
- Direction mapping: A = Monet, B = photo. `G_A2B` = Monet -> photo, `G_B2A` = photo -> Monet.
- Selection: epoch 29 was the best of the 16 JPEG checkpoints (completed epochs 25-40) by the course evaluator's average FID and average MiFID (`outputs/phase0/phase0_summary.csv`). The selection used the same reference images as the final score, so it is selection on the evaluator metric.

## Fixed in-domain evaluation set (not a held-out set)
- A: all 300 sorted Monet images. B: the first 300 sorted photos (exactly the files the official evaluator selects with `N_EVAL = 300`).
- The generators were trained on the complete source datasets (300 Monet, 7,038 photos), so these images were part of the training domains. **All metrics below measure in-domain translation quality, not held-out generalization.** No separate held-out split exists.

## Predictions
- Generated by the repository's `generate.py` (the code path behind the official score): `eval()`, `torch.no_grad()`, no random crop, no flip, sorted inputs, JPEG quality 95. 300 files in `pred_A2B/` and 300 in `pred_B2A/`; no PNG/JPEG mixing (the script refuses to write into a non-empty folder).
- Regenerated on CPU for this evaluation; the original official predictions were produced on the RTX 4090. The recomputed FID differs from the official by < 0.02 (94.989 vs 95.009 A2B; 102.207 vs 102.219 B2A), which is the CUDA/CPU numerical difference. **The official FID/MiFID values stay the course evaluator's values** (`outputs/official_eval/epoch_029/`).

## Metric definitions
- **Features:** torchvision Inception-v3 (IMAGENET1K_V1, `transform_input=False`, `fc=Identity`, 2048-d), Resize(299) -> CenterCrop(299) -> ImageNet mean/std, i.e. the course evaluator's definition.
- **FID / MiFID:** official course notebook, unmodified except the four folder paths (`outputs/official_eval/README.md`). A2B: real photos vs translated Monet; B2A: real Monet vs translated photos. Submission = mean of both directions.
- **KID:** unbiased MMD² with polynomial kernel k(x,y) = (x·y/d + 1)³ (degree 3, gamma = 1/d, coef0 = 1, d = 2048). 100 random subsets of 100 (without replacement) from the 300-vs-300 features, `RandomState(42)`; reported as mean ± std over subsets. The full-sample 300-vs-300 estimate is also given.
- **Precision / recall:** Kynkaanniemi et al. 2019 k-NN manifolds on the Inception features, k = 3, Euclidean distance (k fixed in advance, not tuned). Density / coverage (Naeem et al. 2020, k = 5) are supplementary.
- **Cycle-reconstruction L1:** mean |x − G_back(G_fwd(x))| on a [0, 1] pixel scale, computed on raw tensors before JPEG encoding. A: Monet -> photo -> Monet. B: photo -> Monet -> photo.
- **LPIPS (primary):** input vs cycle reconstruction, `lpips` 0.1.4, `net='alex'` (v0.1), inputs in [-1, 1]. **Supplementary:** input vs direct translation (style change is intended there).
- **Content cosine:** cos(Inception(input file), Inception(JPEG translation)), matched by sorted filename; per-image values in `per_image_content_cosine_*.csv`.
- **Training metrics:** parsed read-only from the raw logs `reproducibility/raw_logs/khushi/task3_khushi_prod_20260930_154246*.jsonl` (epochs 1-29). The logger has no explicit NaN counter; training aborts and writes a `nan_detected` record on non-finite values, so the result is reported as "0 recorded NaN/Inf abort events".
